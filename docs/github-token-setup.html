设置 GitHub Token

用于发版时自动创建 / 更新 GitHub Release、查看 Actions 状态。不会用它做别的事。

第一步 · 生成 token

  1. 打开 github.com/settings/tokens/new
  2. Note 随便填，比如 workbuddy-release
  3. Expiration 选个期限（建议 90 天，到期再续）
  4. 勾权限（见下方说明）
  5. 点 Generate token → 复制那串以 ghp_ 开头的字符
repo ← Release 增删改 read:user ← 只读账号信息

最小可用是 repo。若只想让我读状态、不改Release，public_repo 也够 —— 但那样以后改说明就做不了了。

第二步 · 写到文件（推荐）

在下面这个路径创建文件，把 token 粘进去存盘：

C:\Users\xiong\.workbuddy\.github-token

内容就是 token 那一行，不要加引号、不要加 =。

别把 token 粘进和我的对话里 —— 对话历史会被留存，token 落进去等于长期泄露。
存在这个文件里则完全安全：它在项目目录之外，不会被 git 提交，我也只会读取、不打印。

第三步 · 验证（可选）

存好后在终端跑这行，应该打印出你的 GitHub 用户名：

curl -s -H "Authorization: Bearer $(node C:\Users\xiong\.workbuddy\scripts\gh-token.cjs)" https://api.github.com/user | grep login

备选 · 环境变量

不想落文件的话，设个用户级环境变量也行（关掉终端才生效）：

setx GITHUB_TOKEN "ghp_你的token"

我的脚本两个来源都认，环境变量优先。
